# NexTerm 项目规划

## 产品方向

- **定位**：桌面端多协议连接工作区，一站式管理 SSH/SFTP/数据库/文档/API 调试
- **用户**：开发/运维人员，需要同时管理多台服务器与数据库的日常操作
- **差异化**：数据库工具箱与 SSH 隧道深度集成（PG/MySQL/SQLite 一键隧道连接）、真实终端体验、VS Code 式布局
- **安全基线**：敏感凭据加密存储、SSH host-key 强制 pin（数据库隧道 fail-closed）、压缩冗余特性移除
